# Privacy Policy — LG HVAC for Shelly

Effective date: 30 September 2026

LG HVAC for Shelly is an independent, skills-only community plugin published by Georgi Germanov as an individual.

## Data handled by the plugin

The plugin does not operate its own external server, user database, analytics service, payment system, or account system. It does not independently collect or store passwords, cloud credentials, API tokens, device credentials, precise location, payment information, or other personal data.

The plugin provides instructions and integration guidance inside the ChatGPT environment. Any information a user chooses to provide in a ChatGPT conversation is handled by the ChatGPT service under the terms and privacy practices applicable to that service.

## LG and Shelly services

The plugin is not an official LG Electronics or Shelly Group product and does not itself log in to LG or Shelly accounts. Device scripts or configurations produced with the help of the plugin may use normal device or cloud functionality chosen and configured by the user. Those services have their own privacy practices.

## GitHub

The public project repository is hosted on GitHub. If a user opens an issue or otherwise interacts with GitHub, GitHub may process information according to GitHub's own privacy terms.

## Data retention and deletion

Because the plugin does not operate an independent backend or database, the publisher does not retain a separate copy of user conversations or plugin inputs. Requests concerning data held by ChatGPT, GitHub, LG, Shelly, or another third-party service must be handled through that service.
