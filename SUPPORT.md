# Support — LG HVAC for Shelly

LG HVAC for Shelly is an independent community project maintained by Georgi Germanov as an individual publisher. It is not an official LG Electronics or Shelly Group product, service, integration, or support channel.

## Getting help

For questions, compatibility reports, corrections, or reproducible issues related to the plugin, open an issue in this repository:

https://github.com/drHouse-gif/lg-therma-v-shelly/issues

When reporting an issue, include the exact LG model, controller or gateway where applicable, Shelly model and firmware, interface used, and the relevant documentation reference. Do not post passwords, cloud tokens, private network credentials, service passwords, or other secrets.

## Scope

Support is community-based and provided on a best-effort basis. Model-specific compatibility must be verified against the documentation for the exact equipment before enabling control writes.
